# Changelog

All notable changes to Chat Quote for WooCommerce are documented here.

## 1.2.1

- Improved admin setup with a country dial picker for WhatsApp numbers, save notifications, and checklist progress.
- Improved live preview to match the selected launcher style and added a sticky save bar.
- Enabled support chat without WooCommerce; shop features become available when WooCommerce is active.
- Fixed Freemius pricing AJAX UTF-8 BOM and encoding issues.

## 1.2.0

- Organized Free global widget controls and Pro-only panels.
- Added a Go Pro admin page with a Free vs Pro comparison.
- Added free shop call-to-action style presets; side-by-side and custom layouts remain Pro features.
- Added Free display rules, greetings, and basic Google Analytics, Facebook Pixel, and webhook tracking.
- Added optional request-driven admin email notifications without WP-Cron.
- Added Pro hooks for triggers, multi-agent routing, business hours, Ads tracking, country/login rules, and WhatsApp checkout.
- Improved Chat Bubble settings and Look & Style tabs, inbox fullscreen mode, and mobile chat behavior.
- Separated premium code into the Freemius Pro package.
- Fixed Free settings saves so they do not wipe Pro options, and improved output escaping and hosting-safe handling.
- Updated admin navigation labels and tested WordPress version to 7.1.

## 1.1.1

- Improved plugin description and SEO tags.
- Added step-by-step installation instructions and an expanded FAQ.
- Updated tested WordPress version to 7.0.2.
- Confirmed WordPress 6.1 as the minimum supported version.

## 1.0.0

- Initial release of the WooCommerce chat and WhatsApp quote system.
- Added floating live chat with AJAX messaging.
- Added WhatsApp buttons for product, shop, and cart pages.
- Added an admin inbox with message status tracking and click analytics.
- Added button customization, WhatsApp message variables, and a WordPress dashboard widget.
- Added responsive layouts and clean uninstall support for Multisite.
